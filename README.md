# Gemini Arena Tennis

Play a tennis match against an AI opponent on Gemini Arena’s purple court.

Run `node serve.mjs` from this directory and open **http://localhost:5403/tennis/** in desktop Chrome or Edge. To use a different port, run `node serve.mjs 5413`. The browser build and its game assets are included.

Choose **Camera** for webcam tracking, **Racket sensor** to play without a camera, or **Camera + racket** to use both. For the M5, select **M5-TENNIS-IMU** in the Bluetooth picker, or connect a USB data cable and select **Use USB instead**. Allow camera access when playing a camera mode.
